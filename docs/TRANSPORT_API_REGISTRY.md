# MARSHGO Transport API Registry

Стандарти й рушії — готові; **конкретні фіди операторів — ні**. Для кожного міста/оператора потрібен відкритий feed/API або підключення через MARSHGO Provider API. Записи про реальні фіди живуть у БД (`mobility_providers`, адмінка «Центр керування мобільністю»), цей файл описує стандарти й статус реалізації.

Ліцензії нижче потрібно перевірити в репозиторії перед використанням у продакшні.

| Вид транспорту | Підключення | Що отримуємо | Статус у MARSHGO |
|---|---|---|---|
| Автобус / трамвай / тролейбус / метро / потяг | GTFS | маршрути, зупинки, розклад | **Реалізовано:** завантаження, валідація (файли, зупинки, маршрути, календар), підрахунок типів маршрутів. **Не реалізовано:** збереження розкладу в БД і побудова маршрутів по розкладу |
| Realtime громадського транспорту | GTFS-RT | позиції, затримки, скасування | **Частково:** декодування protobuf і перевірка свіжості. Показу на карті немає |
| Маршрутки | GTFS / Provider API | маршрути, графік | Реєстрація джерела; адаптер Provider API — **немає** |
| Велосипед / e-bike / самокат / мопед / каршерінг | **GBFS** | транспорт, станції, доступність | **Реалізовано:** перевірка, нормалізація в `MobilityAsset`/`MobilityStation`, `GET /mobility/nearby`, плитки «доступно» у клієнті |
| Таксі / on-demand | GOFS / Provider API | доступність, ETA, замовлення | Реєстрація джерела; адаптера немає |
| Carpool | MARSHGO API | водії, місця, pickup/drop-off | **Реалізовано** (власна система) |
| Пішки / велосипед / авто маршрути | Valhalla / OSRM | геометрія, ETA | Авто — OSRM (публічний демо-сервер у dev). Пішки/вело — **не підключено** |
| Multimodal A→B | OpenTripPlanner | єдиний маршрут із пересадками | **Не розгорнуто** |
| Каталог фідів | Mobility Database API | пошук фідів за містом | **Не підключено** (потрібен токен MobilityData) |

## Рушії й стандарти

| Назва | Призначення | Self-host | Примітка |
|---|---|---|---|
| OpenTripPlanner | multimodal routing (OSM + GTFS + GBFS) | так | GraphQL API; ліцензію перевірити (LGPL) |
| Valhalla | авто / пішки / вело, turn-by-turn, map matching | так | ліцензію перевірити (MIT) |
| OSRM | резервний road routing | так | ліцензію перевірити (BSD) |
| GraphHopper | альтернативний routing | так | ліцензію перевірити |
| MapLibre GL JS | рендер карти (вже використовується) | — | BSD |
| GTFS / GTFS-RT / GBFS / GOFS | стандарти даних | — | специфікації; перевірити ліцензії фідів операторів |

## Модель розширення

```
Зовнішнє джерело → адаптер → нормалізація → MobilityAsset/Station → Journey Engine → карта / клієнти
```

Новий оператор з GBFS підключається **без змін коду**: адмінка → «Додати» → «Перевірити» → «Увімкнути». Для GTFS, GTFS-RT, GOFS і Provider API потрібні адаптери (див. `server/mobility/`).

## Що з цього бачить користувач

- Плитка «Велосипед / Самокат / Мопед / Каршерінг» стає «доступно», коли в місті є увімкнений здоровий GBFS-провайдер.
- Тап показує найближчі вільні одиниці та станції (радіус 1,5 км). Бронювання й оплата оренди не реалізовані.
